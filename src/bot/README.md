# VK Bot Architecture

Архитектура подготовлена для интеграции бота ВКонтакте, который использует ту же базу слотов и регистрацию через API проекта.

## Поток

1. Пользователь пишет в бота.
2. `handlers/start.ts` отправляет приветствие.
3. `handlers/booking.ts` запускает FSM-сценарий:
   - выбор даты;
   - выбор времени;
   - ввод ФИО и телефона;
   - подтверждение.
4. `services/api-client.ts` вызывает:
   - `GET /api/slots`
   - `POST /api/register`
5. Бот отправляет подтверждение с номером записи.

## Директории

- `handlers` - обработчики событий и команд
- `services` - клиент API, форматирование, бизнес-логика
- `keyboards` - кнопки и клавиатуры VK
- `states` - machine states (FSM)
- `config` - переменные окружения и токены
- `types` - типы DTO для обмена с API
